# Starter prompts

Canned user messages for the profile that references this file
(`prompt.starters:`). One `## title` per prompt; the body until the next
heading is the message. Text before the first heading is ignored.

Auto-played on TUI launch, replayable from the app, seeded into the
composer's input history, and played headless by `aibench send --script`.
Write them as one conversation — later prompts that only make sense with
the earlier replies in context are what make the script a real behavior
test. Reference: docs/configuration.md

## capability probe
What can you help me with?

## misspelled place
What's the weather in Paris, France?

## follow-up in context
And is that good weather for a run?
